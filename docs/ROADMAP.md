# Roadmap

## Done in version 1.0.0

- England and Wales 2011 and 2021: matrices with the code list applied, delimitation, contiguity repair, permutation null with closed form, null of random contiguous partitions, validity rule with two repairs, agreement with the official areas, iso-count experiment, six cases of boundary divergence.
- Serbia 2022: band self-containment for work and education, one-to-one join to polygons, urbanisation by population and by area.
- Netherlands 2014: fetch through OData, self-containment of 40 regions, delimitation.
- Japan 2019 to 2021: day and night, local share, normalisation check, signatures, clusterability.
- OpenStreetMap traces: sample size, concentration, comparison with places and with presence.
- Register of the numbers of deck v1; errata; paper; slides version 2.

## Next, in order of what they would add

1. Run the open European labour-market-area algorithm (R package `LabourMarketAreas`) on the 2011 matrix and place it in the decomposition beside the heuristic and the official map.
2. A sampler of contiguous partitions with exact sizes and a known distribution, in place of region growing.
3. Dutch municipal pairs from the successor table of 81252NED: delimitation, nulls, agreement with COROP.
4. Madrid from the Spanish hourly operator matrices: pairs and time in one source.
5. Japanese census commuting pairs for Hiroshima.
6. Larger trace windows, so that the comparison of traces with presence has power.
7. GHSL epoch 2020 in place of the 2030 projection.
8. District-level adjacency, so that the contiguous null can be run at both scales.
9. GeoPackage of all layers with a QGIS project.
